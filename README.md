# DATIHAN.PH

Online-first thrift shop storefront for curated pre-loved pieces and pop-up events.

## Design system

### Typography
- **Manrope** — headings
- **Inter** — body and UI

### Colors
- `#281F17` — Dark Brown
- `#6B4E3D` — Brown
- `#DCC9B8` — Light Beige
- `#FBF6F3` — Off-White

## Project roles

- Buyer
- Shop Owner
- Admin

## Development

The frontend is maintained in GitHub. Supabase/database configuration is maintained separately.
